# 雾航司机 Fogline Driver 系统设计规范 v6.1

Oct 5, 2026 · @Charlie

## 0. 版本说明

v6.1 从第一性原理重新收敛了玩法：**地图本身就是游戏**。本文件是所有系统的唯一规范，取代 v6.0；与本文件冲突的旧设计一律以本文件为准。世界观仍沿用《雾潜者 GDD v5.0》。相对 v6.0 的变更汇总见第 17 章。

## 1. 总则

### 1.1 一句话定位

坐在封闭的轨道车里，对着一张不可靠的旧线路图查情报、规划航线、驶入未知、躲开雾中的猎手，把一条条断轨修成自己的网络。

### 1.2 核心体验（按优先级）

1. **规划**：在海图上综合勘测、通告与潮汐预测，自己找出一条可行的路，像看地铁图想换乘、像航海家看海图算潮窗。
2. **驶入未知**：把路线押进只有旧地图的区域，亲眼看着声纳把真实地形一点点扫出来。
3. **冷静应对压迫**：环境是持续的主要威胁，猎手是偶尔逼近的心理压力。玩家能做的只有停、退、换线、熄火、藏。
4. **开辟**：在有限材料下选择修哪几条路、在哪些节点建设施，让网络和捷径成形，像银河城打开捷径、像 Mini Motorways 和 MST 那样做网络设计。

### 1.3 核心循环

```mermaid
flowchart LR
    A[查情报] --> B[规划航线]
    B --> C[打包]
    C --> D[执行：驶入未知]
    D --> E[躲避与应变]
    E --> F[开辟：修路/建设施]
    F -->|勘测、新捷径与新观测者成为新情报| A
```

打包、送货、打捞是辅助系统：打包服务于规划，送货提供目的地，打捞奖励进入未知。它们保持浅而清晰，不追求深度。

### 1.4 设计铁律

- **海图铁律**：所有情报都以海图标记的形式呈现，带位置、时间、来源、可信度四个属性。没有独立的情报、日志或任务界面。
- **记录铁律**：系统负责测量和记录，玩家只负责判断。地形、轨道、接触目标、通告都自动写入海图；玩家不需要手动画图、手动定位或手动三角测量。
- **判断铁律**：系统不替玩家做路线决策。不做自动寻路、自动驾驶、自动扳道岔。
- **视角铁律**：驾驶阶段玩家始终在驾驶舱内，主屏就是海图；不存在车外视角。
- **轨道铁律**：列车只能沿轨道移动。建造只发生在节点和边上，所有可建的边和可建设施的节点都是预设的，并且**数量始终多于玩家能获得的材料**。
- **世界铁律**：雾海是一片连续空间，轨道网络只是嵌在其中的一张图。环境场和猎手存在于连续雾海中，不受轨道约束。
- **涌现铁律**：环境效果由少数规则从地形和潮汐推导而来，不逐条手工设定（见 2.2）。新增环境机制时，优先考虑能否从现有数据推导。
- **真实情报铁律**：雾航通告来自世界中真实发生的观测，经由真实的广播站、覆盖范围和播出时段传播，不凭空生成。
- **单一生命值铁律**：**能源**是唯一决定生死的数值，只能通过格子物品（燃料罐）或在站点恢复。
- **空间铁律**：货物、燃料罐、工具、建造材料共用同一套车厢格子。
- **噪音铁律**：所有发声行为都会计入噪音，噪音是猎手追踪玩家的唯一依据。
- **猎手铁律**：猎手不死。它们没有血条，玩家无法杀死它们，也无法让它们永久消失，只能暂时压制、引开或困住（见 8.7）。
- **无货币铁律**：游戏中没有货币。报酬直接以物品、材料、情报的形式发放。
- **叙事铁律**：剧情线性、单结局；阵营只存在于叙事中，不做声望系统。
- **站点铁律**：站点不做可自由行走的 3D 场景，只做固定视角的站台界面。

### 1.5 范围边界（明确不做）

- 不做交易、市场、价格系统和货币。
- 不做自由铺轨，也不做轨道编辑器。
- 不做自动寻路、自动驾驶和自动扳道岔。
- 不做车外战斗和致命武器。猎手不死，对抗手段只有规避、诱饵、隐藏、逃跑和暂时压制（见 8.7）。
- 不做多结局和阵营声望。
- 不做多人联机。
- 暂不做其他列车与调度系统（远期可能加入其他轨道运输员，届时另行设计）。

## 2. 世界模型

世界在逻辑上是 **2.5D** 的：一张俯视的平面，每一处都有一个地形高度。3D 只负责驾驶舱外壳和站台场景。

**涌现原则**：环境不是逐条手工设定的效果，而是由少数规则从**同一份地形数据**和**一条潮汐曲线**推导出来的。设计者画地形，规则决定哪里深、哪里有流、哪里听得见。

### 2.1 世界的组成

| 组成 | 内容 | 谁在上面移动 |
| --- | --- | --- |
| **地形** | 一张手绘的高度图 `h(x, y)`：高处是山峰和山脊，低处是山谷和洼地 | — |
| **雾面** | 全局的雾面高度 `L(t)`，随潮汐升降 | — |
| **雾海** | 雾面以下的连续空间；深度、雾压、洋流、声音传播都由地形和雾面推导而来（见第 7 章） | 猎手 |
| **轨道图** | 节点和边，嵌在地形上 | 列车 |
| **时间** | 全局时钟，驱动潮汐、洋流、预报事件、广播时段和委托期限 | — |

### 2.2 地形、雾面与深度

- **深度 = 雾面高度 − 所在位置的高度**，即 `depth = max(0, L(t) − z)`。在地表上，`z` 就是地形高度 `h`；在轨道上，`z` 是轨道高程（见 2.4）。
- 山谷深，山峰浅。高出雾面的山峰深度为 0，即**露出雾面**。
- **雾压与深度成正比**，参考海水的规律：雾面处为 1，每深 10 米增加 1 个单位。玩家在仪表上看到的是雾压，设计者思考时使用深度。
- 潮汐只改变一个数：**雾面高度 `L(t)`**。涨潮时，所有地方的深度一起增加。

```
地形高度 h(x, y) ──┐
                    ├──→ 深度 / 雾压                         （见 7.1）
潮汐 L(t) ─────────┤──→ 潮流：沿谷地水道流动，随涨落反转     （见 7.3）
                    ├──→ 声音传播：被地形遮挡                 （见 7.4）
                    └──→ 猎手的活动范围：只在足够深的地方      （见 8.2）
```

### 2.3 节点与边的分类

节点和边都按几个**互相独立的维度**分类。同一个维度在节点和边上尽量对应，玩家学会一套就能读懂两者。

| 维度 | 节点 | 边 | 由谁决定 |
| --- | --- | --- | --- |
| **功能** | 站点 / 道岔 / 端点 | —（边只负责连接） | 设计者预设 |
| **结构** | 地面 / 高架 / 地下 | 地面 / 堤 / 桥 / 隧道（**按段**，见 2.4） | 由轨道高程与地形的关系决定；玩家只能通过"加高路基"改变（见 10.1） |
| **建设** | 站点：是否接入网络；可建设施的节点：设施是否已建 | 已建成 / 铺设中 / 候选（见 2.5） | 玩家修建 |
| **轨道等级** | — | 普通 / 无缝 / 高速 / 磁悬浮（**按段**，见 2.7） | 玩家改造 |
| **缺陷** | — | 断轨 / 落石，是边上的位置（见 2.6） | 世界事件 |
| **认知** | 未确认 / 属实（打勾）/ 不符（打叉）/ 新发现 | 只有旧地图 / 已勘测 | 属于玩家的海图，不属于世界（见 3.1、3.2） |

**深度不是分类**。深度、雾压、洋流随潮汐时刻变化，是由地形和时间算出来的动态量，不写在边上。海图用雾况视图和时间轴把它们显示出来（见 3.7、3.9），**什么时候走、敢不敢走，由玩家自己判断**。

**可通行**也不是单独的状态，而是推导结果：边已建成、并且上面没有断轨，才算**开通**。

#### 节点

| 功能 | 说明 |
| --- | --- |
| 站点 | 可停靠，进入站台界面；接入网络后成为观测者和广播站，并提供产出 |
| 道岔 | 线路分叉的地方，见 4.3。**任何连接三条及以上边的节点都自带道岔**，包括站点 |
| 端点 | 支线的尽头，例如残骸。残骸可以打捞，是探索的奖励 |

- 节点的**结构**跟随它所在位置的轨道高程：地下站点天然隔音，高架站点视野开阔但暴露。
- 部分节点可以建设施（见 10.2）。这是节点的属性，不是单独的功能类型。
- 施工的位置（断点、轨头）**不是节点**，而是边上的位置，见 2.5、2.6。

### 2.4 边的几何与结构

- 每条边都是一条连接两个节点的**真实曲线**，有真实长度。
- 列车沿边**连续移动**，位置记为 `(edgeId, t)`。一条边途经的深度和洋流各处不同，玩家在边的中途就可能遇到涨潮、逆流或猎手。
- 长度决定通过时间和能源消耗；**轨道高程**决定坡度（见 4.2）；**曲率**决定弯道限速（见 2.7）。
- 每条边按固定长度（初始值 250 m）切分为若干**段**。段是结构、轨道等级和修建材料的计量单位。

**结构**由每一段的轨道高程与地形的关系决定：

| 结构 | 判定 | 对玩法的影响 |
| --- | --- | --- |
| **地面** | 轨道贴着地形 | 基准 |
| **堤** | 轨道高于地形，不超过 10 m，下面是实心填方 | 轨道比周围更浅，深度更小；但高出四周，声音不受遮挡 |
| **桥** | 轨道高于地形超过 10 m，下面是空的 | 桥下是雾，**猎手可以从桥下穿过**；完全暴露 |
| **隧道** | 轨道低于地表，在山体内部 | 完全隔音（见 7.4）；但**收不到广播**，主动声纳也看不到外面；玩家不能新挖隧道 |

### 2.5 边的建设状态

| 状态 | 说明 |
| --- | --- |
| **已建成** | 轨道铺满整条边 |
| **铺设中** | 只铺了一部分。**已铺长度**（0 到边长）之外是雾中的空地；列车最远只能开到这个位置，这个位置就是**轨头** |
| **候选** | 预设的、可以新建的边，连接两个已有节点，一段都还没铺。旧地图上可能有，也可能没有 |

- 铺设中的边就是一条通向雾中的死胡同支线，已铺的段永久保留。
- 一条边是不是"已知"，属于海图的认知维度，不是建设状态：旧地图上画着的线，实际可能已建成、已断，甚至从来没修过。

### 2.6 边上的缺陷

缺陷是**边上的一个位置**，不是节点。缺陷是**静默**的，被动声纳发现不了，只有主动声纳或亲自开到跟前才能看到。

| 缺陷 | 处理方式 |
| --- | --- |
| 断轨 | 停在断点前按 B 修复，按缺口覆盖的段消耗材料（见 10.1）；修好前，列车无法越过这个位置 |
| 落石 | 停车后按 B 清理，不消耗材料，但需要一段时间，清理过程会产生噪音 |

- **撞上缺陷**：速度超过安全阈值时，按速度损失能源，易碎货物受损，列车被迫停下。低速时可以安全停住。
- 这条规则让"制动距离必须短于视距"成为驶入未知时的核心约束（见 4.5）。

### 2.7 轨道等级

后期，玩家可以把常走的线路改造成**高速铁路**，甚至**磁悬浮铁路**，在自己开辟的网络里飞驰。等级按段记录，用改造模式升级（见 10.1）。

| 等级 | 限速（相对普通轨） | 噪音 | 改造材料（每段，在上一级基础上追加） | 前提 |
| --- | --- | --- | --- | --- |
| **普通** | 1× | 有轮轨的"咔哒"声 | 新建时的材料（见 10.1） | — |
| **无缝** | 1× | 行驶噪音大幅降低 | 钢轨 1 | — |
| **高速** | 约 2× | 同无缝；超高速时风噪上升 | 钢轨 1 + 石料 2 | 建设线蓝图（见 11.3） |
| **磁悬浮** | 约 4× | 几乎无声，没有轮轨摩擦 | 耐压合金 1 | 建设线蓝图 + 车体的磁浮转向架（见 11.4） |

- **每一段的限速 = min（等级限速，弯道限速）**。弯道限速由曲率决定，所以**弯弯曲曲的谷底线即使升级了也快不起来**，笔直的堤和桥才是高速干线的好位置。选哪几条线升级，本身就是网络设计。
- 海图上每段标出限速，和真实铁路的限速标一样。**超速**时噪音大增、易碎货物受损；在弯道上严重超速会脱轨：列车被迫停下，并损失大量能源。
- **高速只属于已开辟的网络**。边疆仍然是未知路段：制动距离必须短于视距（见 4.5），开得再快的车，在未知里也只能慢慢走。越往后，"在自己的网络里飞驰"和"在边疆里摸索"的反差越大。
- 车辆换装不会消除"快、静、省"三角（见 4.4），**但路网投资可以在特定路线上局部消除它**，就像 Mini Motorways 里的高速路。所以"把材料用在新线上，还是改造常走的老线"是一个长期取舍。

## 3. 海图

海图是游戏的主舞台：它既是驾驶舱主屏（CAB-01），也是站台的海图台（STN-05）。除车辆仪表和车厢格子外，所有信息都在海图上呈现。设计参考真实海运：航海图、航海通告（Notice to Mariners）、NAVTEX 航行警告、潮汐表，以及电子海图系统 ECDIS。

### 3.1 四个图层（由下到上）

| 图层 | 内容 | 可信度 | 视觉 |
| --- | --- | --- | --- |
| **旧地图** | 旧时代印刷的地铁示意图，开局即拥有 | 不可靠：有的线已断，有的站已改名，有的路图上没有；距离和形状失真 | 泛黄的印刷底图，只用 45° 和 90° 的线 |
| **勘测层** | 列车走过的边、声纳扫过的地形（以等高线表示）和静止物体，自动写入。旧地图上没有等高线 | 写入时可靠，但会随时间变旧 | 清晰的实线和等高线 |
| **标注层** | 玩家的手动标注、雾航通告、站点勘测图等带时间戳的情报 | 取决于来源 | 手写或印章风格的标记 |
| **实时层** | 列车位置、接触目标（见第 5 章）、主动声纳回波 | 当前时刻 | 发光的符号 |

旧地图的作用是**引导**：告诉玩家前方"可能"有什么。真正可靠的规划依据是勘测层。路线一旦伸进只有旧地图的区域，就是在押注，这正是探索。

### 3.2 位置与旧地图比对

- 列车行驶在轨道上，所以**列车在勘测层上的位置永远精确**。"我在哪"从来不是问题；真正的问题是"旧地图说前面有路，它说得对吗"。
- 到达一个新节点时，系统自动把它与旧地图上对应的站点或道岔比对，在旧地图上打勾（属实）或打叉（不符），并记录真实名称和位置。

### 3.3 示意图与实测

- 旧地图是 Harry Beck 式的地铁示意图：方正，站距均匀。它**拓扑大致正确，但距离和形状都是失真的**。
- 勘测层画出的是轨道的真实形状和长度。旧地图上看着很近的两站，实际可能隔着一条绕山的长弯道；**真实长度只有勘测之后才知道**。
- **示意视图**只在站台海图台（STN-05）提供：根据玩家已开通的网络，自动生成一张方正的线路图，用来整体规划和欣赏自己的网络。驾驶舱内只使用实测视图。

### 3.4 缩放

海图不切换模式，只有两档缩放，用滚轮或一个按键切换：

| 档位 | 视野 | 显示重点 |
| --- | --- | --- |
| **近景**（驾驶默认） | 跟随列车，约为被动声纳范围的两倍 | 接触目标、地形细节、前方道岔与缺陷 |
| **远景** | 整个区域 | 航线、潮位、标注、整个网络 |

### 3.5 标记模型

每条情报都是海图上的一个标记：

| 属性 | 说明 | 示例 |
| --- | --- | --- |
| 位置 | 节点、边，或雾海中的一个区域 | 5号线 K12 处 |
| 时间 | 观测时刻或预测时刻 | 3 小时前 / 预计 18:00 |
| 来源 | 自己勘测、某个站点或中继站、气象台、匿名信号 | 灯塔站 |
| 可信度 | 决定标记的显示方式：实线、虚线、问号 | 高 / 中 / 低 |

- **标记会过期**：会动的目标（猎手）的标记随时间褪色，过了有效期自动移除；勘测数据也会变旧（例如乱流改变了地形）。
- 标记类型包括：断轨、落石、地形变化、猎手目击、雾象预警、残骸、信号源，以及玩家的自由标注。
- 玩家唯一的手动操作是**放标注**：在海图上放一个图钉，写一句话。标注是可选的，不放也不影响游戏。

### 3.6 情报渠道

渠道只负责把情报写进海图，本身不是独立系统。

| 渠道 | 写入什么 | 时机 | 详见 |
| --- | --- | --- | --- |
| 被动声纳 | 近处地形；声源接触 | 持续 | 5.1 |
| 主动声纳 | 前方远处的地形、静止物体，以及所有目标的当时位置 | 玩家发波时 | 5.2 |
| 站点勘测图 | 附近区段的勘测数据，来源标为该站点（参考空洞骑士的 Cornifer） | 停靠时，或作为委托报酬 | — |
| 雾航通告 | 观测者记录的真实事件 | 广播时段，且玩家在覆盖范围内 | 第 6 章 |
| 剧情通话 | 剧情语音，同时在图上留下相关标记 | 由委托触发，经由广播系统播出 | 6.5 |

### 3.7 时间轴

- 海图下方有一条时间滑杆，向未来拖动可以查看**预测的潮位、洋流和预报事件**。
- 拖得越远，预测越模糊：显示范围变宽，可信度下降。
- **雾啸**等事件以不确定性锥的形式显示，类似台风路径预报图。
- 潮汐有固定周期，可以精确预测；雾啸只能靠预报，并且预报不一定准。

### 3.8 航线规划

- **本区域所有已知的边始终显示在海图上**，包括已开通、未知和候选的边，以及边上已知的缺陷。系统**不给出候选航线**。
- 玩家自己逐个点选节点，拼出一条航线。系统不做寻路，只负责**算账**。
- **悬停查看**：悬停在任意一条边上，显示它的已知信息：长度（未勘测时为区间）、深度剖面、坡度、洋流、上次勘测的时间，以及沿途的标记。
- **深度着色**：在雾况视图中（见 3.9），所有边按"相对于当前耐压上限有多深"染色；拖动时间轴，颜色随潮位变化。
- **航线汇总**：
  - 总距离：已勘测路段为真实长度，未知路段按旧地图估算并显示为区间；
  - 预计能源消耗：同样只有已勘测路段是精确的；
  - 沿途超过耐压上限的路段（随出发时刻变化）；
  - 与时间轴联动的到达时刻，以及该时刻的潮位。
- 航线只是计划：显示为亮线，但不会自动驾驶，也不会自动扳道岔。行驶中可以随时偏离或重新规划。

### 3.9 视图与图层

**等高线与等深线是同一组线。**因为深度 = 雾面高度 − 地形高度（见 2.2），海图只画一组线：

- **等高线固定不动**，那是山。只有勘测过的地方才有等高线，未勘测的区域仍是空白的雾。
- **雾的颜色随潮汐流动**：雾面以下的区域按深度着色。涨潮时颜色往山上漫，退潮时往下退。
- **安全等深线**：参考 ECDIS 的安全等深线，海图把"高度 = 雾面 − 安全深度"的那条等高线加粗标出，随时间轴移动。默认有两条：**耐压线**（列车耐压上限）和**猎手线**（猎手的活动阈值，玩家通过观测得知后才显示）。

**三个视图**：参考 Google Maps 的"底图三选一 + 叠加层"和 ECDIS 的显示类别预设，海图提供三个视图预设：

| 视图 | 用途 | 显示内容 |
| --- | --- | --- |
| **航行**（默认） | 开车 | 线路、缺陷、标记、接触目标、航线；等高线淡淡地垫在底下 |
| **地形** | 看坡 | 清楚的等高线加山体阴影、高度标注；每条边标出坡度（‰），航线上标出上坡和下坡箭头 |
| **雾况** | 看潮看流 | 深度着色、安全等深线、洋流（粒子或箭头，流得越急越密）；与时间轴联动 |

- **始终显示**：列车、接触目标、航线、警报，与当前视图无关。
- **切换**：
  - 海图屏边框上的三个实体按钮，用鼠标点击；
  - **Tab** 依次循环切换三个视图；
  - **拖动时间轴时，自动临时叠加雾况层**，松开后恢复原来的视图，因为拖时间轴本来就是为了看潮。
- **图层面板**：海图角落的面板可以单独开关深度着色、安全等深线、洋流、标注，以及调节旧地图的透明度，供进阶玩家细调。
- **情境预览**（不需要切换视图）：悬停在边上时显示深度剖面和坡度；瞄准发射器时显示投放物的落点和声音的遮挡范围。
- 缩放（见 3.4）与视图互相独立。远景下等高线自动稀疏，只保留主要的等高线。

## 4. 驾驶

驾驶模拟真实机车：没有方向盘，玩家管理的是**动力、制动和惯性**。

### 4.1 操纵件

| 操纵件 | 说明 |
| --- | --- |
| 点火 / 熄火 | 熄火后绝对静音，但无法自主移动（洋流段和下坡可以滑行） |
| 方向手柄 | 前进 / 中立 / 后退。必须停稳才能拨动；停稳后拨到中立，也是停靠操作（见 4.6） |
| 组合手柄 | 牵引和制动共用一根轴：制动 6 级 ← 0 → 牵引 8 级。推向牵引，动力有延迟才会上来。制动 **1–3 级是再生制动**：安静，并把一部分动能回收为能源，但制动力弱；**4–6 级是摩擦制动**：制动力强，摩擦声越来越大，最高级就是最短距离停车，但噪音很大，并可能损伤易碎货物 |
| 道岔 | 把前方最近的对向道岔扳到左股或右股，见 4.3 |

不设单独的紧急制动。列车在主屏海图上显示为一个实时移动的点。按键见 15.6。

### 4.2 物理

- **质量**：货物和车厢的总重量影响加速和**制动距离**。装得越满，越难停下来，因此打包直接影响驾驶。
- **坡度与洋流**：作为外力推动列车。下坡和顺流时需要提前制动；逆流和上坡时更耗能源。坡度的力度由一个可配置的重力系数放大，因为真实铁路的坡度只有百分之一到三，按真实值算体感太弱。
- **牵引力上限**：上坡阻力 = 总质量 × 重力 × 坡度。阻力接近最大牵引力时，速度掉下来；超过时车轮空转，列车开始**溜车**。装得太重，就翻不过陡坡，所以打包直接决定哪些路走得通。
- **限速**：每一段有限速（见 2.7）。超速时噪音大增、易碎货物受损，弯道上严重超速会脱轨。
- **驾驶技巧就是管理惯性**：提前多远收牵引、多早开始制动，怎样不急刹就停在轨头、道岔或站台前。

**高度就是安全，也是势能。**深处危险、高处安全（见 7.1、8.2），重力让这件事同时变成"去"和"回"的难易：

| 方向 | 好处 | 代价 |
| --- | --- | --- |
| **下坡**（往深处） | 熄火也能滑下去，**静音而且不耗能源**；可以用再生制动边下坡边回收能源 | 越走越深；速度越来越快，制动距离越来越长，冲进未知的下坡更需要先发声纳；想快速停下只能用很吵的摩擦制动 |
| **上坡**（往高处） | 去往更浅、更安全的地方 | 必须给牵引，又吵又耗能源，速度还会掉；装得太重可能爬不上去 |

- **下去容易，上来难**：可以悄无声息地滑进山谷，却只能大声地爬出来。这正是驶入未知时最有压迫感的地方。
- **被追时往哪逃**：往下逃速度快，但离猎手的巢更近；往上逃是去安全处，但又慢又吵。
- 再生制动的回收效率低于 100%：下去再上来，能源总是净亏。
- 海图上每条边标出坡度（‰），航线汇总显示累计爬升和下降，预计能源消耗也会把坡度算进去。

### 4.3 道岔

- 道岔是**一条轨道分成两条**的地方。它有两个位置，例如"左股"和"右股"；**列车会驶入道岔当前指向的那条线**。
- **对向进入**（从"一条"驶向"两条"那一侧）：必须在到达之前，把道岔扳到想走的那一股。
- **顺向进入**（从"两条"中的某一股驶向"一条"那一侧）：不需要选择，直接通过。
- **操作**：海图上高亮前方最近的一个对向道岔，并显示它当前的指向。**A 扳到左股，D 扳到右股**，左右以列车的行驶方向为准（倒车时，海图上的道岔图标会标出哪边是"左"）。也可以用鼠标点击海图上的道岔图标。列车压在道岔上时不能扳动。
- 让 A/D 管道岔，是因为玩家对 A/D 的直觉就是"左转、右转"；而列车往哪拐，正是由道岔决定的。
- **扳错或者忘了扳**：列车会驶入另一条线。只能停车、换向后退，退过道岔后扳回，再重新前进。被追击时犯这个错非常致命，这是有意设计的风险。
- 系统不会根据规划的航线自动扳道岔。

### 4.4 快、静、省

速度越快，**噪音越大、能源消耗越快**，但到达更早，更容易赶上潮窗。**快、静、省三者只能兼顾两个**，这是驾驶阶段最核心的持续决策。车体换装（见 11.4）只改变偏向哪两项，不会消除这个取舍。

### 4.5 制动距离与视距

在未知路段，**制动距离必须短于视距**，否则可能撞上看不见的缺陷（见 2.6）。

- 只靠被动声纳时，视距很短，只能低速前进。
- 发一次主动声纳后，前方很远都可以看清，可以放心加速。
- 主动声纳的本质，是**用能源和噪音换速度与安全**。

### 4.6 停靠与发车

停靠不需要专门的按键，而是用真实司机进站的动作完成：

1. 进站前，海图上高亮**站台区段**，即这条边上的一小段。
2. 减速，让列车**停在站台区段内**。停得准不准，本身就是驾驶技巧。
3. 停稳后，**把方向手柄拨到中立**，即开始停靠：站台灯亮起，转入站台界面。
4. 如果停在站台区段外，海图上提示"未对准站台"，需要再前后挪动。
5. **不停车直接开过去也可以**：站点只是图上的一个节点，路过并不强制停靠。

发车时，玩家回到停在站台上的驾驶舱，方向手柄处于中立，自己拨到前进后出发。

## 5. 侦测

### 5.1 被动声纳

- 常开、静默、耗能极低。
- **范围很短**：列车周围一小圈。
- 自动把圈内的粗略地形写入勘测层。
- 遵循声音传播规则，会被地形遮挡（见 7.4）。
- **只能发现会发声的东西**：猎手、洋流的轰鸣、残骸的异响。静默的缺陷、残骸和潜伏的猎手，它都发现不了。
- 发现的声源以**接触目标**的形式显示在实时层（见 5.3）。

### 5.2 发射器：主动声纳与投放物

车头的**发射器**负责一切"向外发出去"的东西：声纳脉冲和投放物共用同一个按键、同一套手势。以后新增投放物，只需要定义它"落地后做什么"，操作不变。

**统一手势：**

| 操作 | 声纳脉冲 | 投放物 |
| --- | --- | --- |
| 单击 Space | 360° 全向发波，范围最近 | 放在列车当前位置 |
| 按住 Space 蓄力 | 波束角度逐渐收窄，探测距离随之变远 | 射程逐渐变远（初始值：1.5 秒内从 0 到约 400 m） |
| 鼠标 | 决定波束方向 | 决定发射方向 |
| 预览 | 扇形 | 落点圈，以及落地后声音的可听范围（按地形遮挡着色） |
| 松开 Space | 发射 | 发射 |

**选择弹种：**

- **1 = 声纳脉冲**，是默认弹种，不限次数，每次消耗能源。
- **2 = 装填位里的投放物**。投放物必须先从车厢格子**装填**：按住 Shift 转身，右键投放物选"装填"，约 2 秒。装填位初始只有 1 个。
- **射出投放物后，自动切回声纳脉冲**。默认状态永远是声纳，误射只可能发生在刚按过 2 之后。
- 两种弹种的预览形状、仪表颜色和按键音都不同。
- 平静时提前装填好，被追时只需按 2 再按住 Space；没装填，就得当场转身翻格子。这几秒的手忙脚乱是有意设计的。

#### 主动声纳

- 每次发波消耗大量能源，产生高噪音，并且会特别吸引 EMP 型猎手（见 8.5）。
- **每次发波的能源消耗和噪音固定**。蓄力只是在"覆盖面"和"距离"之间分配同一份能量：角度越窄，看得越远。
- 蓄力收窄后，可以**看得很远**，远超被动声纳的范围。
- **能看到所有东西，包括静默的**：落石、断轨、残骸、隐藏的岔路，以及静止潜伏的猎手。但看不到被地形挡住的地方，例如山脊背后（见 7.4）。
- 结果是**那一瞬间的快照，之后一直显示**：
  - 静止的东西（地形、缺陷、残骸）写入勘测层，永久保留，直到被新的勘测覆盖；
  - 会动的东西（猎手）以那一刻的位置留下带时间戳的标记，之后逐渐褪色。
- 近距离发波会让猎手累积硬直值（见 8.7）。

#### 投放物

- 发射时有一声中等的"咚"，会暴露列车的位置，但比主动声纳轻。
- 落点有误差，射得越远误差越大（初始值：距离的 ±10%）。飞行途中不计算撞山，只看落点。
- 投放物落地后发出的声音同样遵循声音传播规则：**扔到山脊背后，猎手就听不见**。

| 投放物 | 落地后 |
| --- | --- |
| **声诱饵** | 延迟约 3 秒后开始发声，持续一段时间，给猎手制造一个假的"最后听见的位置" |
| **声爆弹** | 一声巨响，落点附近的猎手大量累积硬直值（见 8.7） |
| **信标浮标** | 长时间低声持续发声，作为长期诱饵 |
| **中继浮标** | 一段时间内为附近的接触目标提供交叉方位，加速三角定位 |

### 5.3 接触目标

被动声纳发现的声源，按精度分为三级，全部显示在实时层：

| 等级 | 条件 | 海图显示 |
| --- | --- | --- |
| **方位** | 初始能力：被动声纳听到 | 从列车伸出的一段模糊扇形区域。方向由声纳测出，远近由响度粗估；声音越强，扇形越窄、越短 |
| **估计位置** | 已安装**测向仪**（见 11.2），且列车在移动中；或者在中继站覆盖范围内 | 自动三角定位，扇形收缩成一个不确定椭圆。列车移动得越久、角度变化越大，椭圆越小。椭圆足够小时，显示目标大致的移动方向 |
| **确认** | 主动声纳回波 | 精确光点，之后转为带时间戳的标记并褪色 |

- 目标停止发声后，它的接触显示会逐渐扩散、变淡，直到消失。
- 三角定位完全自动，玩家不需要任何手动操作。

### 5.4 声音

- 驾驶舱使用三维音效，玩家可以凭耳朵判断声源的方向。
- **猎手当前的行为阶段通过声音传达，而不是界面**：游弋时是低沉的远鸣，搜索时是断续的探测声，追猎时是越来越近、越来越急的声音。

## 6. 雾航通告

雾航通告是一个**真实模拟**的情报网络：每一条通告都来自世界里真实发生的事，经由真实的广播站在真实的时间播出。

### 6.1 观测者

| 观测者 | 观测内容 |
| --- | --- |
| 已接入网络的站点 | 监听范围内的猎手活动、断轨、落石、地形变化 |
| 中继站 | 同上，监听范围更大 |
| 雾航司气象台 | 根据真实的潮汐和雾啸模拟生成预报，带预报误差 |

- 观测者有真实的位置和**监听范围**。事件只有真实发生在监听范围内，才会被记录。
- 记录带有**观测误差**：例如猎手的位置记录为一个区域，而不是精确的点。

### 6.2 广播

- 每个广播站（已接入网络的站点、中继站、气象台）都有真实的位置、**覆盖半径**和**固定的播出时段**。参考 NAVTEX：各站轮流在自己的时段播出。
- 雾压越大，覆盖半径越小。
- 观测到的情报，要等到该站的下一个播出时段才播出，所以**情报天然有延迟**。

### 6.3 网络转播

- **已接入网络的站点之间互相转播**：A 站的观测会沿轨道网络传到 B 站，由 B 站在自己的时段播出。
- 孤立的站点只播自己附近的观测。
- 因此**图的连通性直接决定了情报的流动**：玩家修的每一条路，同时也是一条情报线路。

### 6.4 接收与时效

- 播出时，玩家在覆盖范围内就能收到，并自动写入标注层；不在范围内就错过了。
- 停靠站点时，可以翻阅该站的播出记录，补收它最近播过的通告。
- 接收能力可以通过侦测线的接收机升级提高（见 11.2）。
- 每条通告都带观测时间；标记随时间褪色，过了有效期自动移除。

### 6.5 剧情通告

剧情通告和剧情通话走同一条管道：剧情事件交给某个具体的广播站，由它在自己的时段播出。玩家无法区分脚本通告和模拟通告。

## 7. 环境

环境是主要威胁。所有环境效果都由地形 `h(x, y)` 和雾面 `L(t)` 推导而来（见 2.2），玩家通过所经过的边来感受它们。地形同时决定了深浅、水流和声音，所以玩家读懂地形，就读懂了危险。

### 7.1 雾压与耐压

- **雾压由深度决定**（见 2.2），是最核心的环境数值。列车承受的雾压，按其所在位置的轨道高程计算。
- 列车有**耐压上限**，通过耐压线升级提高（见 11.1），这是银河城式的主要进度门槛。
- 超过耐压上限属于**软门槛**：仍然可以进入，但能源消耗随超出量急剧上升。略微超出可以冒险冲过去，大幅超出则必死无疑。
- 怕压货物有自己的**承压阈值**，可能低于列车的耐压上限：车能过的深度，货物不一定能过。

### 7.2 潮汐

- 雾面高度 `L(t)` 按固定周期升降，可以精确预测，并显示在时间轴上（见 3.7）。
- **涨潮**：所有地方的深度一起增加。原本安全的谷底路段可能超过耐压上限；猎手的活动范围向浅处扩张（见 8.2）。
- **退潮**：深度减小，部分山脊可能露出雾面，猎手被迫退回谷底。

### 7.3 洋流

参考真实海洋：**潮流沿海底的沟谷流动，涨潮时往里流，落潮时往外流，谷越窄流得越急。**

- 设计者在地形上标出几条主要的**谷地水道**及其走向。
- 每条水道上的流向随潮汐的涨落**反转**；流速与潮位变化的快慢成正比，并随水道收窄而加快。
- 洋流对列车的作用，取其沿轨道方向的分量：顺流省能源，熄火时可以滑行；逆流加倍消耗。
- 因为洋流由潮汐决定，它同样可以预测，并显示在时间轴上。玩家可以学会"等落潮，顺流滑出洼地"。

### 7.4 声音传播

声音规则同时适用于猎手的听觉、被动与主动声纳、观测者的监听，以及声诱饵。

- **距离衰减**：声音越远越弱。
- **地形遮挡**：声源与听者之间的连线如果被地形挡住，声音大幅衰减。实现上，沿两点之间的连线在高度图上采样，检查是否有地形高过这条线。
- 由此自然得出：
  - 山脊挡声，两条山谷之间互相听不见；
  - **隧道不需要特殊规则**：隧道段的轨道高程低于地表，列车在山体内部，连线必然被挡住；
  - 主动声纳看不到山脊后面的东西。
- **深海声道**（可选扩展）：深处的声音传得更远，参考海洋中的深海声道。

### 7.5 其他雾象（扩展）

以下雾象为后续扩展。设计时应同样优先从地形和潮汐推导，而不是独立设定。

| 雾象 | 形态 | 对玩家的影响 |
| --- | --- | --- |
| 寒流 | 局部区域 | 经过时持续额外消耗能源 |
| 乱流 | 局部区域，例如水道收窄或地形急变处 | 颠簸会损伤易碎货物，并提高噪音 |
| 漩涡 | 特殊位置，例如水道交汇处 | 把列车卷向指定方向，或强制改道 |
| 雾啸 | 罕见的预报事件 | 雾面短时间内大幅上涨，必须及时赶到高处或站点 |

## 8. 猎手

### 8.1 定位

猎手不是常驻的敌人，而是一种**持续的心理压力**。玩家感知到它的次数，应该远多于真正和它遭遇的次数。

### 8.2 索敌

核心规则：**猎手追的是"最后听见声音的位置"，而不是列车本身。** 它并不知道列车在哪。

| 环节 | 规则 |
| --- | --- |
| 活动范围 | 只在**深度大于一定值**的地方游弋。涨潮时范围向浅处扩张，退潮时退回谷底，所以"深处危险、高处安全"，并且危险程度随潮汐变化 |
| 可听半径 | 由列车当前的噪音决定，越吵传得越远；遵循声音传播规则，会被地形遮挡（见 7.4） |
| 定位精度 | 声音越大越准；远处的轻微声响，它只知道大概方向 |
| 警觉值 | 每次听见都会累积，并随时间衰减；高到一定程度，就进入下一个行为阶段 |
| 移动目标 | 游向**最后听见的位置** |
| 近距离感知 | 距离非常近时（例如 50 米内），即使列车完全静音也可能被发现 |

由此产生的玩法：熄火后滑走，它扑向的是你刚才的位置；声诱饵制造一个假的"最后听见位置"；信标是长期的假目标；被逼得太近时，单靠静音不一定能躲过去。

### 8.3 移动速度

| 阶段 | 速度 | 设计意图 |
| --- | --- | --- |
| 游弋 | 慢于列车的安静巡航速度 | 可以悄悄避开它 |
| 搜索 | 中等 | — |
| 追猎 | **快于列车的安静巡航速度，慢于全速** | 想甩开它只能全速，但全速很吵，它会一直跟着。逃跑能成功，但要用能源换距离，直到进入隧道或避难所 |

### 8.4 行为阶段

```mermaid
stateDiagram-v2
    [*] --> 游弋
    游弋 --> 警觉: 听到噪音
    警觉 --> 搜索: 警觉值继续上升
    警觉 --> 游弋: 警觉值衰减
    搜索 --> 追猎: 定位到列车
    搜索 --> 游弋: 搜索超时
    追猎 --> 搜索: 失去目标
    追猎 --> 攻击: 进入攻击距离
    攻击 --> 游弋: 攻击后离开一段时间
    追猎 --> 硬直: 硬直值满
    搜索 --> 硬直: 硬直值满
    硬直 --> 搜索: 数秒后恢复
    游弋 --> 搁浅: 所在处深度低于活动阈值
    搁浅 --> 搜索: 深度恢复
```

硬直和搁浅见 8.7。

### 8.5 猎手类型

两种猎手共用同一套索敌系统，只有攻击方式不同。

| | **追击者**（近战） | **EMP 型**（远程） |
| --- | --- | --- |
| 索敌 | 听噪音 | 听噪音，对**主动声纳**格外敏感 |
| 攻击 | 贴身撞击 | 在远处释放电磁脉冲 |
| 效果 | 扣大量能源（约 25%–35%），损坏若干货物，然后离开一段时间 | **致盲**：实时层消失数秒到十几秒，海图屏出现雪花（旧地图、勘测层、标注层保留）；同时扣少量能源 |
| 威胁的东西 | 能源 | 信息 |
| 克制它的打法 | 静音、诱饵、避难所、地形 | 少发主动声纳；依赖被动声纳和已有勘测；提前熟悉路线 |
| 登场 | 第一幕 | 第二幕起 |

攻击本身不会直接导致游戏结束，但可能让能源归零。

### 8.6 玩家的应对

| 应对 | 作用 | 代价 |
| --- | --- | --- |
| 减速 / 熄火 | 降低或消除噪音，让它失去踪迹 | 时间流逝；野外静等会缓慢消耗能源；潮窗可能关闭 |
| 倒车 / 改道 | 离开它的搜索区域 | 绕远路；需要正确扳动道岔 |
| 发射声诱饵 | 把它引向别处 | 消耗一个投放物；没提前装填就得当场转身装填；发射声会暴露自己 |
| 进入隧道 / 避难所 | 隔音，它会失去目标 | 前提是附近有隧道，或避难所已经建好 |
| 全速冲过去 | 赶在它围过来之前通过 | 很吵，能源消耗快，它会一直跟着 |
| 近距离发主动声纳 | 让它硬直，争取几秒逃跑时间 | 极吵，可能惊动更远处的猎手；反复使用效果递减 |
| 引进洼地，等退潮 | 把它困住，直到下一次涨潮 | 要读懂地形和时间轴；引诱的过程本身很危险 |

### 8.7 不死与压制

猎手**不会死**：没有血条，玩家无法杀死它，也无法让它永久消失。参考生化危机的暴君：可以放倒它，但它总会再站起来。威胁永远留在世界里，玩家能改变的只是它**此刻在哪、在做什么**。

**硬直值：**

- 每个猎手有一个硬直值，受到强烈的声音冲击时累积，随时间衰减。
- 累积满后进入**硬直**：原地失去行动能力数秒，之后直接进入搜索阶段，警觉值保持在高位。
- **它会习惯**：每次硬直后，硬直上限提高，同一种手段反复使用效果递减；一段时间后才恢复。压制只能争取时间，不能代替规避。

| 硬直来源 | 说明 |
| --- | --- |
| 近距离主动声纳 | 发波点离猎手越近，累积越多；贴脸发波几乎必然让它硬直 |
| 冲击类投放物 | 例如声爆弹：落点附近的猎手大量累积硬直值 |

列车本身不能撞伤猎手；撞击只会伤到列车。

**压制方式：**

| 方式 | 持续时间 | 做法 |
| --- | --- | --- |
| 硬直 | 数秒 | 见上，用来争取逃跑时间 |
| 引开 | 数十秒或更久 | 声诱饵、信标 |
| 隔绝 | 直到列车离开 | 隧道、山脊遮挡 |
| **困住** | 直到下一次涨潮 | 利用活动范围的深度规则，见下 |

**搁浅与困住**（由活动范围规则推导，不额外设定）：

- 猎手平时会随退潮退回深处。只有被诱饵、追猎拖住时，它才可能错过退路。
- 退潮时，如果猎手所在的洼地与深处之间的浅鞍部先降到活动阈值以下，它就被**困在**这片洼地里。
- 如果洼地本身也降到阈值以下，它就**搁浅**：不能移动，听觉大幅减弱，但近距离感知仍然有效，贴着它经过仍可能把它惊醒。
- 雾面回升、深度回到阈值以上时，它苏醒，并在原地开始搜索。
- 地形上只要存在被浅鞍部隔开的洼地，就自然存在可以困住猎手的地方。玩家可以在涨潮时把猎手引进洼地，再等退潮把它关在里面。

## 9. 资源

### 9.1 资源表

| 资源 | 类型 | 占格子 | 获得 | 消耗 | 说明 |
| --- | --- | --- | --- | --- | --- |
| **能源** | 生死数值 | 否 | 燃料罐、站点补满 | 行驶、主动声纳、超压、寒流、野外怠速、撞击、猎手攻击 | 归零即游戏结束；上限由动力模块决定 |
| 噪音 | 瞬时数值 | 否 | 所有发声行为 | 随时间自然衰减 | 猎手追踪的依据 |
| 格子物品 | 五类，见 9.2 | 是 | — | — | — |

### 9.2 格子物品

物品按**怎样离开车厢格子**分为五类。每一类只有一种交互方式，玩家学一次就会用。

| 类别 | 怎样离开格子 | 例子 |
| --- | --- | --- |
| **货物** | 到站交付 | 委托货物，带属性标签（见 12.2） |
| **补给** | 右键 → 使用，立即生效 | 燃料罐（相当于生化危机的草药） |
| **投放物** | 装填进发射器，再发射出去（见 5.2） | 声诱饵、声爆弹、信标浮标、中继浮标 |
| **材料** | 施工时自动扣除（见 10.1） | 钢轨、石料、耐压合金 |
| **工具** | 放在格子里就生效，或使用后持续生效 | 固定带（防颠簸货损）、压载（临时提高耐压） |

所有物品都有三个通用属性：**尺寸**、**重量**、**标签**（易碎、怕压、发声、有期限等）。重量影响加速、制动距离和爬坡能力（见 4.2）。

**材料：**

| 材料 | 现实对应 | 代表的取舍 | 尺寸 / 重量 | 来源 | 用途 |
| --- | --- | --- | --- | --- | --- |
| **钢轨** | 钢轨和扣件；1 件 = 一段所需的钢材 | **稀缺** | 1×2，重 | 委托报酬、站点产出、打捞 | 新建、修断轨、无缝与高速改造 |
| **石料** | 道砟、填方 | **沉重**：不稀缺，但又重又占地方 | 2×2，很重 | 站点大量供应 | 堤段、加高路基、高速改造 |
| **耐压合金** | 耐压结构件 | **银河城钥匙** | 1×1，轻 | 主线和人物委托报酬、深处打捞 | 耐压与侦测升级、磁悬浮改造 |

### 9.3 设计原则

- 车厢格子的核心张力是：**这一趟要带多少燃料罐求稳、带多少材料做长期投资、带多少投放物和工具应对路上的意外**。所有物品都有重量，带得越多，制动距离越长、越难爬坡。
- **耐压合金的竞争**：耐压升级、侦测升级和磁悬浮改造都需要耐压合金。"升级车，还是修路"是整局游戏的核心经济取舍。
- **材料只有三种**，每种代表一种别的材料表达不了的取舍：钢轨是"缺不缺"，石料是"拉不拉得动"，耐压合金是"往哪里投资钥匙"。新增材料种类之前，必须证明现有三种无法表达某个重要的取舍。

### 9.4 数值平衡原则

- 每趟行程的能源消耗约为满能源的 40%–70%，逼迫玩家携带燃料罐，或者规划途经站点的路线。
- 主动声纳单次消耗约为满能源的 8%–12%。
- 任何时刻，候选边与设施的总造价约为玩家可获得材料的 2–3 倍，确保"修哪条"始终是取舍。
- **数值要能被看见，而不是被记住**：航线规划的能耗预估、候选边的造价，都和模拟使用同一套计算，玩家看到的就是实际会发生的。
- 单位取整、好记：满能源 100，一罐燃料是 1/4 箱，一次主动声纳约 1/10 箱，一件钢轨是一段。

## 10. 建网

建网有三重意义：**修路**让往返更快，**建设施**让区域更安全，**接入观测者**让情报更多。

### 10.1 修路

断轨和候选边都是预设的。所有施工都需要把材料**实际运到现场**，修路本身也是一趟运输。施工会耗时并产生噪音。

**造价由结构自动推出**，设计者不手填。每一段的材料由它的结构决定（见 2.4）：

| 结构 | 每段材料 |
| --- | --- |
| 地面 | 钢轨 1 |
| 堤 | 钢轨 1 + 石料（每填高 5 m 一份） |
| 桥 | 钢轨 2（钢轨加梁） |
| 隧道 | 不能新建 |

- 一条边的造价 = 各段之和；断轨的造价 = 缺口覆盖的各段之和；清理落石不消耗材料。
- **深度不影响造价**。深处的段用同样的材料，但施工期间列车要在那里待很久：挑哪个潮位动工、能不能扛住雾压、会不会引来猎手，都由玩家自己判断。
- 悬停在候选边或断轨上，海图逐段显示材料图标和总价，例如"钢轨 5 · 石料 3"。玩家不需要自己算。

| 类型 | 修法 | 说明 |
| --- | --- | --- |
| **断轨** | 停在断点，按一下 B | 断轨是点状损坏，像一扇门。修复自动进行一段时间，期间持续发出噪音；再按 B 或推牵引即中断。材料可以分多次投入，进度保留。修好后整条边开通 |
| **新线（候选边）** | **铺轨模式，边开边修** | 参考真实的铺轨机：一边缓慢前进，一边在车头前方铺下轨道，见下 |

**铺轨模式：**

1. 开到**轨头**（已铺轨道的尽头），按 B 进入铺轨模式。车头放下铺轨装置，海图上的轨头开始闪烁。
2. 用 W/S 照常驾驶，但速度被限制在**爬行速度**。列车往前开多远，轨道就铺多远，沿这条候选边预设的走向延伸，玩家不需要控制方向。
3. **按距离消耗材料**：每铺完一段，按这一段的结构扣除材料，格子里的材料随之减少。
4. **全程持续发出施工噪音**。被动声纳照常工作，玩家可以一边铺轨一边留意周围的动静。
5. **随时可以停**：
   - 拉回牵引，列车停下，铺轨也随之停止，没铺完的那一段不扣材料；
   - 再按 B 收起铺轨装置，恢复正常速度，可以倒车撤离；
   - 材料用完时，铺轨自动停止。
6. 铺轨时前方是真正的未知：被动声纳范围很短，铺得太快可能撞上落石。是否先发一次主动声纳看清前路，仍然由玩家判断。

**其他规则：**

- 铺到一半的新线，是一条**通向雾中的死胡同支线**。已铺的段永久保留，并自动写入勘测层；不需要额外的进度条。
- 一趟带的材料通常不够铺完整条新线，需要多次往返运材料。轨道越修越长，运材料的路也越来越远。
- 铺轨时，**驾驶、侦测和开辟在同一时刻发生**。铺轨的噪音也让这里成为猎手最可能出现的地方。
- 新线铺到另一端的节点后，整条边开通。

**改造模式**（升级已建成的段）：

- 在已建成的边上停车，按 B 进入改造模式。操作和铺轨模式完全一样：用 W/S 爬行前进，开过的每一段按目标规格扣除材料并完成改造。
- 改造前，在海图上选择改造的目标：
  - **轨道等级**：无缝、高速、磁悬浮（见 2.7）；
  - **加高路基**：每级让轨道高程 +5 m、深度 −5 m，地面段随之变成堤段。可以让一段路在涨潮时也低于耐压上限或猎手的活动阈值，同时会改变两端的坡度。
- 改造期间同样持续发出施工噪音。

### 10.2 节点设施

设施只能建在预设的可建设施的节点上，可建的类型由建设线解锁（见 11.3）。

> **待重新设计**：下表是初步设想，设施的作用还没有经过推敲。例如避难所与隧道、站台的作用重复。设施真正的价值，可能在于**改变图的结构**（在危险的长边中间加一个补给节点）和**改变信息的结构**（增加观测者），见第 18 章。

| 设施 | 作用 |
| --- | --- |
| 信标 | 持续发声，可以作为长期诱饵，把猎手引离某片区域 |
| 中继站 | 观测者兼广播站（见第 6 章）；在其覆盖范围内为接触目标提供交叉方位，加速三角定位 |
| 避难所 | 隔音；可以在其中躲避猎手和雾啸，并恢复少量能源 |

### 10.3 网络产出与观测

- 站点**接入网络**的条件：它与起点站之间存在一条全部已开通的路径。
- 接入网络的站点：
  - 每次停靠都能领取少量物资（燃料罐、钢轨、石料、投放物或工具，每个站点类型固定）；
  - 成为观测者和广播站，并与其他接入站点互相转播（见 6.3）。
- 因此"先连哪个站"本身就是一个战略选择，玩家需要像构造生成树一样考虑连接顺序。

## 11. 车辆成长

好的升级应该**带来新的可能，或者改变取舍**。单纯的数值提升会冲淡核心张力，尤其是"快、静、省"这个三角。成长分为四条线：三条**钥匙线**和一条**换装线**。

### 11.1 耐压（钥匙线）

- 线性提升耐压上限。每一级都会打开新的深度区域，是银河城的主门槛。
- 消耗耐压合金，在站台车间（STN-04）进行。

### 11.2 侦测（钥匙线，重点深化）

信息是这个游戏的核心资源，侦测线是最值得深化的成长线。

| 升级 | 效果 |
| --- | --- |
| 被动声纳 | 提高监听半径 |
| 测向仪 | 开启自动三角定位，接触目标从"方位"升级为"估计位置"（见 5.3） |
| 主动声纳 | 提高最大探测距离，或缩短蓄力时间 |
| 发射器 | 增加装填位，或提高投放物射程 |
| 接收机 | 在更深处、更远处也能收到雾航通告 |

- 消耗耐压合金，在站台车间进行。

### 11.3 建设（钥匙线）

| 升级 | 效果 |
| --- | --- |
| 设施蓝图 | 解锁可建的设施类型：信标、中继站、避难所 |
| 轨道蓝图 | 依次解锁高速轨、磁悬浮轨的改造（见 2.7） |

- 通过主线和人物委托获得。

### 11.4 车体（换装线）

车体升级是**换装**，不是数值提升：每个选项在快、静、省之间各有偏重，**没有一种全面更强**。

| 部件 | 说明 | 示例 |
| --- | --- | --- |
| 动力模块 | 决定马力、噪音、能耗和能源上限 | **静音电机**：安静、省能源，但马力小；**重型柴油机**：马力大，但很吵、很耗能源 |
| 车厢 | 加挂车厢能扩大格子容量，但车更重，制动距离更长 | 普通货运车厢；**隔音车厢**（可屏蔽发声货物的噪音，但容量较小） |
| 转向架 | 决定列车能在哪种轨道上发挥速度 | 普通转向架；**磁浮转向架**（在磁悬浮轨上悬浮飞驰，但更重，在普通轨上更费能源） |

- 动力模块和车厢通过委托报酬或打捞获得，在站台车间自由更换，不消耗材料。

### 11.5 不属于升级的东西

- **投放物**（声诱饵等）是物品，不是升级。新的投放物通过委托报酬或打捞获得。
- **能源上限**跟随动力模块，不单独升级。

## 12. 驱动力

### 12.1 委托

| 委托类型 | 来源 | 作用 |
| --- | --- | --- |
| 主线委托 | 剧情推进 | 手写；推进主线，报酬通常包含耐压合金或建设蓝图 |
| 人物委托 | 固定收货人 | 手写；连续交付后解锁该人物的故事段落，并给出新的目的地或勘测图 |
| 派单 | 站点调度台 | 程序化生成；作为补给来源，报酬是燃料罐、钢轨、石料、投放物和工具 |

- **委托就是钥匙**：送到货的同时，往往会打开新的委托、情报或建网机会。送货、建网、推进剧情合为一件事。
- 委托之外的另一个驱动力是**好奇心**：海图上看得见但去不了的地方，例如断掉的线、雾中的站名、只收到一半的信号。

### 12.2 货物属性

| 属性 | 效果 |
| --- | --- |
| 重量 | 所有货物都有，影响加速、制动距离和爬坡能力 |
| 怕压 | 超过阈值深度会受损 |
| 易碎 | 颠簸、最高级制动、乱流、撞击会受损 |
| 发声 | 持续叠加噪音（放在隔音车厢里可以屏蔽） |
| 活物 / 易变质 | 有时限 |

- 货物受损会降低报酬，完全损毁则委托失败。货物状态是每件货物自己的状态，不计入能源。

## 13. 时间

- **行驶中**，时间实时流逝，具体比例待定（见第 18 章）。
- **站台中**，时间暂停，但玩家可以主动选择"等待到某一时刻"，例如等退潮再出发。
- 时间驱动：潮汐、洋流变化、雾啸预报、广播时段、委托期限、货物时限，以及标记的褪色。
- **时间的代价**：在野外熄火等待会缓慢消耗能源；潮窗会关闭；有期限的委托会到期；可能错过广播时段。

## 14. 玩法循环

### 14.1 单趟循环（示例）

委托：把一箱药送到灯塔站，报酬是 1 块耐压合金。

| # | 阶段 | 玩家行为与决策 |
| --- | --- | --- |
| 0 | 获得目标 | 读委托：药箱占 2×2 格、怕压；目的地已在旧地图上标出。 |
| 1 | 读图 | 在海图上自己比较路线：A 线近，但有断轨，后半段未勘测；B 线已勘测，但中段很深。 |
| 2 | 查情报 | 拖动时间轴：18:00 涨潮后，B 线深段会超过耐压上限。标注层上，A 线 2号站附近有一条猎手目击通告，观测于 3 小时前。 |
| 3 | 打包 | 药箱、燃料罐 ×2、钢轨 ×3、声诱饵 ×1，出发前把声诱饵装进发射器。多带一罐燃料求稳，还是多带钢轨修捷径？带得越多，制动距离越长，爬坡越吃力。 |
| 4 | 行驶 | 管理牵引和制动，在快、静、省之间权衡；在道岔前扳到 A 线。 |
| 5 | 修路 | 在断轨处投入钢轨。全部投入，还是留一件以防万一？ |
| 6 | 进入未知 | 旧地图上的线实际已经偏移。发主动声纳看清前方后加速，还是只靠被动声纳慢速前进？ |
| 7 | 猎手信号 | 被动声纳出现一个模糊扇形，探测声越来越近。熄火静等、把诱饵射到山脊另一侧、扳道岔进隧道支线，还是全速冲过去？ |
| 8 | 意外发现 | 主动声纳扫出一条旧地图上没有的岔路，尽头有一处残骸。现在去打捞？格子满了丢什么？还是先标注下来？ |
| 9 | 抵达 | 交付，获得合金。灯塔站接入网络，成为新的观测者；收货人提到另一个地方，下一个目的地出现。 |

### 14.2 一段遭遇（示例）

> 列车在近景视图里沿航线前进。被动声纳边缘出现一个淡淡的扇形，同时传来低沉的远鸣。玩家收回牵引，扇形慢慢收窄，并在测向仪的作用下缩成一个椭圆，出现一个箭头：它正朝轨道游过来。远鸣变成断续的探测声。
>
> 前方 300 米有一个对向道岔，旧地图上画着一条通向隧道的支线，但只是虚线。能源 62%。玩家把道岔扳向支线，熄火，靠惯性滑过道岔。探测声越来越近，椭圆扫过列车刚才的位置……然后转向主线方向。
>
> 玩家在隧道口重新点火，低速驶入。这条支线变成实线，旧地图上的虚线被打上一个勾。

这段遭遇中，玩家只做了四个决定：收牵引、扳道岔、熄火、重新点火。其余都由系统自动记录。

### 14.3 阶段循环（一幕）

1. 抵达新区域，大部分只有旧地图，勘测层几乎空白。
2. 接取本幕主线委托，得知需要到达的深处目标。
3. 通过人物委托和派单积累材料与勘测数据。
4. 在候选边与设施之间做取舍，建出自己的网络和观测网。
5. 用耐压合金在耐压、侦测升级与磁悬浮改造之间分配，打开更深的区域，或让已开辟的网络更快。
6. 完成本幕最后一单主线委托，进入下一幕。

### 14.4 长期循环（整局）

- **空间**：从青藏岛周边逐步向深处延伸，直至零号海沟。
- **车辆**：耐压逐级提高，侦测逐步精确，车体换装适应不同的跑法。
- **网络**：勘测层逐步覆盖旧地图；玩家建出的网络让往返更快、更安全，情报更丰富。后期把干线改造成高速铁路乃至磁悬浮，在自己的网络里飞驰，而边疆依然只能摸索前进。
- **叙事**：序幕（黑盒）→ 第一幕（漩涡）→ 第二幕（航线）→ 第三幕（深渊）→ 尾声，沿用 v5.0 的剧情结构，由主线委托串联。

### 15.5 跳转规则

- 顶层：SYS-01 → SYS-02 → SYS-05 → STN-01；STN-01 发车进入 CAB-01，停靠后回到 STN-01；能源归零进入 SYS-06。
- 驾驶舱内切换面板只是视角移动，游戏不暂停。转身看车厢（CAB-04）期间，列车保持当前方向、牵引和制动，这是有意设计的风险。
- 所有站台子界面只能返回 STN-01。例外：在 STN-02 接单后，可以一键进入 STN-03 装载委托货物。
- **发车前置条件**：所有已接委托的货物都已装车；能源大于零。航线规划是可选的。
- 任意界面按 Esc 进入 SYS-04；叠加层不改变当前界面和游戏状态，警报（OVL-03）优先级最高。

### 15.6 输入与交互

**平台**：PC，键盘 + 鼠标。暂不支持手柄。

**分工原则：左手开车，右手看图。**驾驶全部用键盘，鼠标只操作海图和格子，玩家看图时也能开车，不需要切换模式。

**驾驶舱镜头**：固定的座位视角，海图屏占据画面中央的大部分区域。鼠标**不转视角**，光标始终停在海图屏上。

#### 驾驶（键盘）

| 功能 | 按键 | 说明 |
| --- | --- | --- |
| 组合手柄 | W / S | W 往牵引方向推一级，S 往制动方向拉一级；按住连续推拉 |
| 道岔 | A / D | 把前方最近的对向道岔扳到左股 / 右股（见 4.3） |
| 方向手柄 | E / Q | E 往前拨（后退 → 中立 → 前进），Q 往后拨；只能在停稳时拨动。在站台区段内拨到中立即停靠（见 4.6） |
| 发射器 | Space | 单击：声纳 360° 发波，或把投放物放在脚下；按住蓄力：声纳收窄波束、投放物射得更远；鼠标瞄准，松开发射（见 5.2） |
| 选择弹种 | 1 / 2 | 1 = 声纳脉冲（默认）；2 = 装填位里的投放物。射出投放物后自动切回 1 |
| 点火 / 熄火 | 长按 F | 长按约 1 秒，避免误触 |
| 施工 | B | 在轨头：进入或退出铺轨模式；在已建成的边上：进入或退出改造模式；在断点或落石前：开始或中断修复、清理（见 10.1） |
| 转身看车厢 | 按住 Shift | 松开转回；转身期间看不到海图，列车保持当前状态 |

| 时间轴 | 拖动海图底部的滑杆 | 预览未来；松开后回到"现在"。驾驶中拖动不会暂停时间 |
| 标注 | 右键放置图钉 | 选择图标（危险、残骸、疑问、备注），可以附上一句话 |
| 瞄准发射器 | 按住 Space 时移动鼠标 | 见 5.2 |

#### 车厢格子（按住 Shift 时）

| 功能 | 操作 |
| --- | --- |
| 移动物品 | 左键拖拽 |
| 旋转 | 拖拽中按 R |
| 使用（补给） | 右键物品 → 使用 |
| 装填（投放物） | 右键物品 → 装填，约 2 秒，装进发射器的装填位 |

装填必须转身进行：被追击时没提前装好，就得转身、找到诱饵、右键装填，这几秒钟的手忙脚乱是有意设计的。

#### 站台（鼠标）

全部用鼠标操作：点击接受和交付委托，拖拽物品装车，在海图台上规划航线和拖动时间轴，点击"发车"。

## 16. Game State 状态机

### 16.1 全局状态

```mermaid
stateDiagram-v2
    [*] --> Boot
    Boot --> MainMenu
    MainMenu --> Loading
    Loading --> Station
    Station --> Transit: 发车
    Transit --> Station: 停靠
    Transit --> Cutscene: 剧情触发
    Station --> Cutscene: 剧情触发
    Cutscene --> Station
    Cutscene --> Transit
    Transit --> GameOver: 能源归零
    GameOver --> Loading: 读档
    Station --> Paused
    Transit --> Paused
    Paused --> Station
    Paused --> Transit
    Paused --> MainMenu
    Cutscene --> Ending: 尾声
    Ending --> MainMenu
```

| 状态 | 时间流逝 | 可存档 | 说明 |
| --- | --- | --- | --- |
| Boot | — | 否 | 初始化服务、读取设置 |
| MainMenu | 否 | 否 | SYS-01/02/03 |
| Loading | 否 | 否 | 加载场景和存档数据 |
| Station | 否（可主动等待） | 是（自动） | 所有站台界面 |
| Transit | 是 | 否 | 所有驾驶舱界面 |
| Cutscene | 视剧情 | 否 | 固定演出 |
| Paused | 否 | 否 | 记录暂停前的状态，恢复时返回 |
| GameOver | 否 | 否 | 显示失败原因 |
| Ending | 否 | 否 | 尾声与制作名单 |

### 16.2 Transit 子状态

```mermaid
stateDiagram-v2
    [*] --> EngineOff
    EngineOff --> Idle: 点火
    Idle --> Moving: 挂向、给牵引
    Moving --> Idle: 停稳
    Idle --> EngineOff: 熄火
    Moving --> Coasting: 熄火（靠惯性、坡度或洋流继续移动）
    Coasting --> Moving: 点火
    Coasting --> EngineOff: 停稳
    Idle --> Repairing: 在断点或落石前按 B
    Repairing --> Idle: 修复完成、清理完成或中断
    Idle --> Laying: 在轨头按 B
    Laying --> Idle: 再按 B 收起铺轨装置
    Idle --> Upgrading: 在已建成的边上按 B
    Upgrading --> Idle: 再按 B 收起
    Idle --> Docking: 停在站台区段内，方向手柄拨到中立
    Docking --> [*]
```

- **Laying（铺轨模式）**：列车可以用 W/S 前后移动，但限速为爬行速度；前进越过轨头时自动铺轨并消耗材料。停车不会退出铺轨模式，只有再按 B 才会退出。
- **Upgrading（改造模式）**：与铺轨模式相同，只是作用在已建成的段上，按改造目标扣除材料。

- 猎手和雾航通告都是**并行运行的独立系统**，不作为 Transit 的子状态。

### 16.3 车辆状态（并行）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| energy | float | 唯一的生死数值 |
| energyMax | float | 由动力模块决定 |
| noise | float | 当前噪音强度，随时间衰减 |
| pressureLimit | float | 耐压上限 |
| position | (edgeId, t) | 当前所在的边，以及在边上的位置 |

| controllerNotch | int −6–8 | 组合手柄级位：负数为制动，正数为牵引 |
| layingMode | enum 无/铺轨/改造 | 当前施工模式 |
| payload | enum 声纳/投放物 | 发射器当前弹种 |
| launcherSlots | list | 发射器装填位里的投放物 |
| bogie | id | 当前转向架 |
| mass | float | 总质量，由编组与格子内容计算 |

### 16.4 存档数据

- 当前幕、委托进度、人物委托进度。
- 世界时间。
- 勘测层、标注层以及所有标记（含时间戳）；旧地图比对结果。
- 已开通的边、各断轨的投入进度、各新线已铺设的段数（即轨头位置）、已清除的落石、已建设施。
- 各广播站待播出的通告队列和播出记录。
- 各猎手的位置、行为阶段、硬直值与习惯程度。
- 道岔的当前指向。
- 耐压上限、侦测升级、建设解锁、动力模块、车厢编组与格子内容、仓库内容。
- 当前所在站点（只在 Station 存档，所以读档一定回到站台）。

## 17. 相对 v6.0 的变更

| 项目 | v6.0 | v6.1 |
| --- | --- | --- |
| 核心 | 七个并列的玩法模块 | 以海图为中心的单一循环 |
| 驾驶舱 | 多个面板分散显示信息 | 主屏就是海图 |
| 交易 | 缺货/余货标签、价格计算、以物换物 | **删除** |
| 货币 | 配给券 | **删除**，报酬直接给物品 |
| 生死数值 | 燃料、电量、分区完整度 | **统一为能源**，用燃料罐恢复 |
| 主要威胁 | 怪物 | **环境**；猎手是持续的心理压力 |
| 猎手 | 噪音触发追踪 | 在连续雾海中自由移动，追踪最后听见的位置；分为追击者（近战）和 EMP 型（远程致盲）；**不死**，只能硬直、引开、隔绝或困住 |
| 环境 | 雾压、洋流 | 雾压与潮汐联动，另有洋流、寒流、乱流、漩涡、雾啸 |
| 情报 | 电台是唯一的情报来源 | 统一为海图标记；雾航通告由真实观测、广播与网络转播产生 |
| 地图 | 线路图面板 | 旧地图 / 勘测层 / 标注层 / 实时层四层，外加时间轴；航行 / 地形 / 雾况三个视图，等高线与安全等深线合一；玩家自己拼航线，系统只算账 |
| 边与地图形状 | 未明确 | 边是有真实长度的曲线，列车沿边连续移动；旧地图是方正的示意图，与真实形状和距离不符；轨头、断轨、落石都是边上的位置，不是节点 |
| 地形 | 无 | 一张高度图加一条潮汐曲线，推导出深度、雾压、潮流、声音遮挡和猎手的活动范围 |
| 修路 | 修复预设断点 | 断轨原地修复；新线进入铺轨模式，边开边铺，按段的结构自动推出材料；已建成的段可以改造为无缝、高速、磁悬浮轨，或加高路基；候选边多于资源，外加节点设施和网络产出 |
| 边与节点的分类 | 未明确 | 按功能、结构、建设、轨道等级、缺陷、认知六个维度分类；深度是动态量，不是分类 |
| 材料 | 轨件、耐压合金 | 钢轨（稀缺）、石料（沉重）、耐压合金（钥匙）三种 |
| 物品 | 未分类 | 按离开格子的方式分为货物、补给、投放物、材料、工具五类 |
| 声纳 | 被动瀑布图 + 主动发波 | 被动短程、只能发现发声物体；主动声纳与投放物共用一个发射器（Space 发射，1/2 选弹种），单击近、蓄力远、鼠标瞄准；主动声纳能看见静默物体；接触目标分方位、估计位置、确认三级，三角定位自动完成 |
| 驾驶 | P/R/N/D/L 挡位 + 油门刹车 | 模拟机车：方向手柄（E/Q）、组合手柄（W/S，制动分再生与摩擦）、质量与惯性、坡度与牵引力上限、按段限速；道岔用 A/D 手动扳动；停靠 = 停在站台区段内并把方向手柄拨到中立 |
| 升级 | 车厢与改装 | 耐压、侦测、建设三条钥匙线，加车体换装线 |
| 电台 | 接收 + PTT 发射 | 只接收 |
| 声学共振 | 有 | **删除** |

## 18. 待定问题

1. **能源的正式名称**：炉温、电量还是别的，需要符合世界观。
2. **时间比例**：行驶中现实 1 秒对应多少游戏时间；潮汐周期和广播时段的长度。
3. **猎手数值**：可听半径、警觉值曲线、各阶段速度、攻击的能源扣除量与货损规则、硬直值的累积与习惯曲线，需要通过试玩调试。
4. **剧情回应**：除了文本选项之外，以后是否恢复 PTT 发射。
5. **其他轨道运输员**：远期加入时，是否引入调度、信号与共享网络。
6. **节点设施的作用**：信标、中继站、避难所需要从"玩家在路上遇到的困境"出发重新设计（见 10.2）。
